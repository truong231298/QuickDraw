# 🎨 QuickDraw AI

Real-time sketch recognition using PyTorch and computer vision. QuickDraw AI
classifies hand-drawn objects from a dataset, image upload, or webcam crop. It
includes a reproducible training entry point, top-k inference, a FastAPI
service, and ONNX export.

## What is included

- Configurable 20-class CNN baseline and balanced per-class `.npz` downloader
- Reproducible stratified split, affine augmentation, and best checkpoints
- Training curves, top-3 accuracy, and macro precision/recall/F1
- Interactive drawing canvas and real-time webcam crop inference
- FastAPI `POST /predict` and `GET /health` endpoints
- ONNX export and ONNX Runtime support in the same inference apps
- Evaluation reports with confusion matrix, latency, throughput, and model size
- Docker image for serving the API

## Setup

Requires Python 3.10 or newer. Create and activate an environment, then run:

```bash
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
pip install -e .
```

Download and prepare 10,000 bitmap drawings per class with:

```bash
python scripts/download_dataset.py
```

The script writes the `.npz` archives into `data/`; use `--count 20000` for a
larger sample. See [data/README.md](data/README.md) for details. Class names
and order live in [config/classes.txt](config/classes.txt).

Train (limit the number of examples per class with `--max-per-class`):

```bash
python scripts/train.py --epochs 10 --max-per-class 10000
```

The best validation checkpoint is saved to `models/quickdraw.pt` and contains
both model weights, ordered class names, and validation metrics. Training curves
are saved to `demo/training_curves.png`.

## Train in Google Colab

Open [notebooks/QuickDraw_Colab.ipynb](notebooks/QuickDraw_Colab.ipynb) in
Google Colab and select a GPU runtime. In PowerShell, create the source bundle
from the project folder:

```powershell
.\scripts\create_colab_bundle.ps1
```

Upload `quickdraw-colab-source.zip` when the notebook prompts for it. The
notebook downloads the dataset, trains the model, and downloads
`quickdraw.pt`. Copy that file into the local `models/` directory; the canvas,
webcam app, and API can load it directly. The checkpoint contains its class
labels and validation metrics.

## Inference

Run the webcam app (press `q` to exit):

```bash
python -m app.webcam --model models/quickdraw.pt
```

Inference converts to grayscale, detects dark or light backgrounds, crops to
the sketch bounds, and centers the resized drawing before classification.

Or draw directly in an interactive canvas. Use the mouse to draw, `p` to
predict, `c` to clear, and `q` or Escape to quit:

```bash
python -m app.canvas --model models/quickdraw.pt
```

Start the HTTP API:

```bash
uvicorn api.main:app --reload
```

Upload a sketch:

```bash
curl -X POST http://localhost:8000/predict -F "file=@demo/sketch.png"
```

Response shape:

```json
{
  "prediction": "cup",
  "confidence": 0.94,
  "top_k": [
    {"class": "cup", "confidence": 0.94},
    {"class": "book", "confidence": 0.03}
  ]
}
```

Choose the number of candidates with `?top_k=5`. Set `QUICKDRAW_MODEL` to use
a checkpoint at a different path. Uploads support PNG, JPEG, WebP, and BMP up
to 10 MiB. The API returns a clear 503 until a trained checkpoint is available.

Export the trained model:

```bash
python scripts/export_onnx.py --checkpoint models/quickdraw.pt
```

The export writes `models/quickdraw.onnx` and a matching JSON class metadata
file. Both the API and local applications accept either model format. To use
ONNX in the API from PowerShell:

```powershell
$env:QUICKDRAW_MODEL = "models/quickdraw.onnx"
uvicorn api.main:app --reload
```

Evaluate the checkpoint on the deterministic held-out split:

```bash
python scripts/evaluate.py --data data --checkpoint models/quickdraw.pt
```

This writes JSON metrics, per-class precision/recall/F1 CSV, and a confusion
matrix under `reports/evaluation/`. If you trained with a custom `--seed`,
pass the same value to evaluation.

Build and run the API container after training a model:

```bash
docker build -t quickdraw-ai .
docker run --rm -p 8000:8000 --mount type=bind,source="$PWD/models",target=/app/models quickdraw-ai
```

PowerShell:

```powershell
docker build -t quickdraw-ai .
docker run --rm -p 8000:8000 --mount "type=bind,source=$((Resolve-Path .\models).Path),target=/app/models" quickdraw-ai
```

## Dataset and evaluation

The default class list contains apple, book, bowtie, candle, cloud, cup, door,
envelope, eyeglasses, guitar, hammer, hat, ice cream, leaf, scissors, star,
t-shirt, pants, lightning, and tree. Edit `config/classes.txt` and provide
matching archives to train a different class set. Reported benchmark values
are generated by training and evaluation commands; this repository makes no
precomputed accuracy or latency claims.

## Repository layout

```text
api/                    FastAPI app
app/                    Webcam inference app
app/canvas.py           Interactive drawing canvas
config/classes.txt      Ordered class configuration
data/                   Downloaded archives (ignored by git)
scripts/                Download, train, evaluate, and ONNX export
reports/                Generated evaluation reports
src/quickdraw_ai/       Dataset, CNN, training, preprocessing, inference
models/                 Local checkpoints (ignored by git)
```
